# Elasticsearch-The-Official-Distributed-Search-Analytics.md
A VirtualBox-based DevSecOps lab that demonstrates the setup of Elastic SIEM (Elasticsearch, Kibana, Logstash), Snort IDS, UFW logging, and NGINX load balancing. Logs from multiple VMs are collected via Filebeat and visualized in Kibana for security monitoring and analysis.


# Elasticsearch Distributed Search & Analytics

This project was created to understand how Elasticsearch works in a distributed environment and how it can be used for search and analytics.

## Purpose

The main goal of this project is to explore:

* How data is indexed in Elasticsearch
* How distributed search works
* How fast and efficient querying is achieved
* How Elasticsearch handles scalability and large datasets

## Summary

By building this project, I aimed to gain hands-on experience with Elasticsearch and better understand its role in real-world data systems.
